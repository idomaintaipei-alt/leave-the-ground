# 離開地面｜三句話，三個營地

一個給「沒在閱讀、正在挫折」的人的網頁。
進來先有三句開場，再點一個現在的狀態，山會帶你走三個營地，每個營地一句山岳文學裡的話、一段白話、一個留給你的問題。
**停留就是上升**：字慢慢出現，停滿十四秒（或手指往上滑）才能往上。營地之間有一段「風景」：沒有字、高度不動、十秒後才能走。
**不是每個爬山的人都想攻頂**：每個營地都可以「今天到這裡就好」，停在那句話，不結算。
分享到 Threads 時會自己畫一張卡（天色照心情、山稜、那句話、出處、網址），手機直接帶圖分享，電腦則先存下來。

引句取自臉譜出版「meters 山岳文學書系」（詹偉雄策畫．選書．導讀，2020–2024，共十本）各書中文版的書介、導讀與書名，不抄書的內文。
這個網頁是一個讀者做的，與出版社無關。

## 山是活的（手機才有的感官，都要使用者自己點允許；不允許也照常能玩）

- **真實時間**：天色跟現在幾點走（深夜／黎明／清晨／白天／傍晚／黃昏／夜），心情只染 35%。標題會寫「黃昏 18:20 的山」。
- **手的傾斜**（選心情那頁的「讓山感覺你的手」）：手機平放，字沉下去；舉起來，字才浮出來。iPhone 會跳一次權限詢問。
- **山認得你**：來過幾次、上次什麼時候、最高到過幾公尺，記在這支手機裡（localStorage），不上傳。第二次來開場第一句會變成「你回來了。上次是 N 天前。」
- **海拔**（「讓山知道你在多高」）：用定位拿海拔，高度計從那裡起算。室內常量不到，會寫「這裡量不到高度」。

## 檔案

- `index.html`：全部都在這一個檔，沒有其他相依。
  - 開頭 `BOOKS`：十本書的書名、副標、作者、連結。
  - `QUOTES`：每一句引句。欄位：`b` 第幾本、`m` 適合哪些狀態（stuck 撐不下去／tired 很累／lost 迷路／quit 想放棄／any）、`q` 引句、`by` 出處、`why` 一段白話、`ask` 留給讀者的問題。**要改文字、加句子，改這裡就好。**
  - `INTRO`：進來先看到的三句開場。
  - `MOODS`：每種狀態的山形與第一營地的開場句。
  - 風景那一行字（「不用做什麼。」）和「今天到這裡」那段話在 HTML 的 `#s-view`、`#s-stay` 區塊。
  - `STAY`：每個營地至少停幾秒（預設 14）。

## 上線（GitHub Pages）

1. GitHub Desktop → Add local repository → 選這個資料夾 → Publish repository（名稱建議 `leave-the-ground`，可勾 Private 也可公開；Pages 要公開倉庫或付費方案）。
2. GitHub 網頁 → 該倉庫 → Settings → Pages → Source 選 **Deploy from a branch**，Branch 選 `main`、資料夾 `/ (root)` → Save。
3. 等一兩分鐘，網址會是 `https://<帳號>.github.io/leave-the-ground/`。
4. 之後改 `index.html` → commit → push，網頁自動更新；分享到脆時在網址後面加 `?v=日期` 可避開快取。

## 給文壇朋友看的三個問題

1. 三個營地、每個停十四秒，節奏對嗎？太慢還是太快？
2. 每句底下那段「白話」和「問題」，語氣對嗎？哪裡太像在說教？
3. 五種狀態（撐不下去／很累／迷路了／想放棄／只是想看看山）夠不夠？少了哪一種？
